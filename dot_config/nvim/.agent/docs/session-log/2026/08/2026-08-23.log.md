### Decisions made
- Config lives in `pickers`, not on the `gr` keymap. Picker-level config applies to every
  invocation path — keymaps, `:Telescope lsp_*`, future callsites — so it cannot regress the
  way per-keymap opts did (the first attempt covered 4 of 9 pickers for exactly that reason).
- Path columns are unbounded rather than widened. A column is truncated only if it carries a
  `width` key (`entry_display.lua:89`), so any fixed width — including a dynamic
  `vim.o.columns` fraction — reintroduces the bug at some window size. Rejected
  `fname_width = 0.5` for that reason: it moved the cliff from 30 to 50 columns.
- Accepted a ragged code-text column as the cost of never truncating the path. Keeping the
  text aligned requires a fixed path column; the two are mutually exclusive. Developer chose
  path precedence with the code text retained.
- `lsp_document_symbols` hides its path: single-buffer picker, so the path is identical on
  every row and the width is better spent on symbol names.
- `builtin.diagnostics` left untouched — `gen_from_diagnostics` already renders the path as
  its `remaining` column.

### Problems hit
- Root cause was not `path_display` (the telescope issue the developer linked, #1958, is
  about `find_files`). `gen_from_quickfix` hardcodes a 30-column `path:lnum:col` field
  (`make_entry.lua:449`) and truncates head-first, so same-directory results all render as
  the identical common prefix. `find_files` is immune because `gen_from_file` has no
  fixed-width column.
- First fix used `show_line = false`, which removed the inline code text entirely. Developer
  wanted it kept, so it was replaced with `quickfix_path_first`, whose two columns both omit
  `width`. Dropping the fixed column also dropped its alignment padding — separator widened
  to `" ▏ "` and the text is trimmed of leading indentation to compensate.
- `gen_from_lsp_symbols` orders columns path, symbol, kind, so the path is structurally never
  last and no width setting can free it. Needed the wrapper that reorders to symbol, kind,
  path. Its kind highlighting is preserved by mirroring telescope's `lsp_type_highlight`,
  which is file-local to `make_entry.lua` and cannot be required.
- A lazy `__index` metatable for building `entry_maker` on first access was written and then
  abandoned: telescope merges picker opts with `pairs`, which never fires `__index`. Built
  eagerly instead — safe because `opts()` already requires telescope submodules.
- Shared displayers must avoid fractional widths: `entry_display` memoizes a resolved
  fractional width from the first window it renders into. All bounded columns therefore use
  absolute widths.
