# Preferences

Learned working preferences. Format: `- P-NNN (date) rule`.

- P-001 (2026-08-18) A commit message request always means ONE commit containing every changed
  file — never split a session's work into multiple commits or per-file groups, and do not offer
  a split. Title it with the primary change's type and cover the other concerns as bold-headed
  body paragraphs.
