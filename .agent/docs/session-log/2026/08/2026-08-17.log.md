### Decisions made

- **Wall clock, not HEAD commit time, is the source of truth for "now"** in `log.ts`
  (`resolveLogDate`) and `spec.ts` (`specNew`). This supersedes D02-2. The old rule stranded every
  session on a stale date until the day's first commit, and `spec new` could hard-fail `no-date`
  in a fresh repo.
- **Task-group ids are `Step <n>`, legacy `T<n>` still parses.** `GROUP_HEADING_RE` accepts both so
  existing spec-tasks files keep working; templates and `spec-format.md` emit `Step 1`.
- **`after/ftplugin/markdown.lua` is the only viable gate point** — Nvim 0.12's bundled
  `ftplugin/markdown.lua` calls `vim.treesitter.start()` unconditionally, before any FileType
  autocmd runs. The parser is deliberately left reachable so render-markdown still renders.
- **The nvim harness lives in the chezmoi source tree only.** chezmoi does not manage
  `dot_config/nvim/.agent/`, so `~/.config/nvim` never receives it; agents edit here and deploy
  selectively.
- **lazy.nvim's update checker stays off**, not merely quieted — the leak is one timeout timer per
  spawned `git fetch`, so `notify = false` would have kept the handle growth.
