**nvim: telescope LSP picker paths.** `gen_from_quickfix` hardcoded a
30-column `path:lnum:col` field that truncated head-first, making
same-directory results render identically; `gen_from_lsp_symbols` ordered
columns so the path could never be last. Filled `pickers = {}` with two entry-
maker wrappers (`quickfix_path_first`, `symbols_path_last`) covering all nine
LSP pickers, and hid the path on `lsp_document_symbols` (single-buffer, so the
path is redundant). Config lives at the picker level, not on the `gr` keymap,
so it can't regress per-callsite the way a partial per-keymap fix already had.

**nvim: markdown conceal_lines root cause.** The 2026-08-17 fix capped the
markdown treesitter highlighter by file size instead of removing the actual
cost: `$VIMRUNTIME/queries/markdown/highlights.scm`'s `(#set! conceal_lines
"")` on fenced-code delimiters forces a full `on_conceal_line` sweep
(re-parse + full injected-tree walk) every screen row, repaid every keystroke
— 35.4ms/redraw on a 2179-line spec, gone after the fix. Strips the directive
from the query text at runtime via `vim.treesitter.query.set` (patches text,
not the `.scm` file, so upstream fixes still flow through), and stops/restarts
already-attached highlighters so the patch actually takes. Removed the
now-unnecessary size gate and the `injections.scm` overrides Nvim core already
covers by info-string (moved the two genuinely custom entries to
`vim.treesitter.language.register` aliases). Added a column-independent
markdown checkbox toggle (`<C-Space>`, `<leader>T`) as a byproduct of touching
the ftplugin. Decision record superseded; perf baseline refreshed.
