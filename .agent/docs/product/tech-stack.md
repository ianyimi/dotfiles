# Tech Stack

## Language + Runtime
- Primary: Shell (bash/zsh) + chezmoi Go templates (`.tmpl`)
- Secondary: TypeScript on Bun >= 1.3.14 (`harness/` CLI), Lua (Neovim, Hyprland config), YAML (Ansible)

## Repo Structure
- Single chezmoi source directory (`~/.local/share/chezmoi`), standard git repo (`ianyimi/dotfiles`)
- `dot_*` / `run_*` chezmoi naming; `harness/` is an embedded Bun+TS project

## Dotfile Management
| Tool | Purpose |
|------|---------|
| chezmoi | Dotfile manager with templating; `dot_` prefix maps to `.` on deploy |
| git | Version control |
| Bitwarden CLI (bw) | Secret injection via chezmoi template functions (self-hosted vault, reached over Tailscale) |

## System Provisioning
| Tool | Purpose |
|------|---------|
| bootstrap.sh | One-command fresh-machine setup (macOS + CachyOS) |
| Ansible | OS provisioning: `dot_bootstrap/macos.yml`, `dot_bootstrap/cachyos.yml` (deployed to `~/.bootstrap/`) |
| Homebrew (macOS) / pacman (CachyOS) | Package management |

## Shell Environment
| Tool | Purpose |
|------|---------|
| Zsh (+ autosuggestions, syntax highlighting) | Primary shell; `dot_zshrc.tmpl` is the source of truth for all aliases |
| Starship | Prompt |
| tmux + tmuxinator | Multiplexer + 25 session templates (`dot_config/tmuxinator/`) |

## Desktop / Window Management
| Platform | Stack |
|----------|-------|
| macOS | AeroSpace + SketchyBar + JankyBorders; WezTerm + Ghostty terminals |
| CachyOS | Hyprland (Lua config, `dot_config/hypr/`) + noctalia bar/launcher + uwsm |

## Editor + CLI Tools
- Neovim (Lua config, `dot_config/nvim/`), lazygit, lazydocker, gh + gh-dash, fzf, ripgrep, bat, aerospace-monitor daemon

## Agent Tooling
| Tool | Purpose |
|------|---------|
| `harness/` (@zaye/harness) | Platform-agnostic agent harness CLI; `.agent/` source of truth, generated `.omp/` + `.claude/` bridges; Bun+TS, yaml dep only |
| `pi-agent-base/` | Global Pi/omp agent config, synced to `~/.pi/agent/` by `run_after_sync-pi-agent-base.sh.tmpl` |
| `.pi/`, `.omp/`, `.claude/` | Project-local agent setups (`.omp`/`.claude` generated by harness sync) |

## Development Runtimes
| Runtime | Manager |
|---------|---------|
| Node.js | fnm |
| Bun | installed for harness/ |
| Go | Homebrew/pacman |
| Lua | Homebrew + luarocks |

## Secret Management
- Bitwarden self-hosted (Vaultwarden >= 1.35 on server); templates in git are public-safe, secrets injected at `chezmoi apply`
- Never modify vault structure or secret references without explicit approval

## Platform Support
- macOS (Apple Silicon) and CachyOS (Arch Linux) are both first-class; guard OS differences with chezmoi `{{ if eq .chezmoi.os ... }}` templating
